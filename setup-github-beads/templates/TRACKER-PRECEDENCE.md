## Tracker routing precedence

`docs/agents/issue-tracker.md` is authoritative.

GitHub Issues owns human-visible planning, Wayfinder work, specifications,
tracer tickets, approval, and final status. Beads may show selected planning
scopes through the repository's pull-only mirror, but generic Beads instructions
that claim universal tracker ownership apply only to implementation work that
the user has authorized and routed into Beads.
